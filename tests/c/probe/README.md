# probe — 1:1 gcc-vs-Mnemo corpus

C programs (Mnemo subset) used to check that Mnemo's output matches gcc byte for byte.

- `cases/*.c` — the test programs (generated by `gen*.py`, plus a few written by hand).
- `run.sh [dir]` — compiles each file with gcc and with Mnemo and compares stdout and exit code.
  Files whose first line is `// SKIP` are skipped: they exercise undefined or unspecified
  behaviour (signed int overflow, `sizeof` of a pointer, argument evaluation order).
- Status: every non-skipped case passes.

Regenerate: run the `gen*.py` scripts in this directory (`python3 gen.py`, `python3 gen2.py`, …).
